# 動画素材の差分監査

**一部の音声を直した後、変更していないはずの音声・字幕まで変わっていないかを確認するツールです。** 許可した音声の尺変更に合わせて、後続の時刻が正確に移動しているかも調べます。

Python 3.12の標準機能だけで動き、ログイン・通信・有料APIは不要です。[MIT License](LICENSE)で利用できます。

[English](README.md) · [入力形式](INPUT-FORMAT.md) · [比較の仕様](COMPARISON-CONTRACT.md) · [検証記録](VALIDATION.md)

## どんな編集に使うか

例えば「2か所の音声だけを差し替え、ほかの音声と字幕文はそのままにする」編集に使います。同じ音声ID・順序を持つ修正前後のPCM音声と、指定形式の字幕JSONが必要です。

WAVフォルダ・SRT・MP4から必要な情報を作る変換ツールではありません。字幕文の改稿、ページ追加・削除、素材順序の入替は対象外です。**PASSでも、発音・話し声と字幕の同期・スライドの見た目・完成動画を承認したことにはなりません。**

## 同梱の例を動かす

このフォルダで、Python 3.12を`python`で起動できる状態で実行します。

```sh
python fixtures.py synthetic_demo_new
python audit.py synthetic_demo_new/修正前 synthetic_demo_new/修正後 synthetic_demo_new/policy.json --output new_result.json
python -m unittest -v
```

生成先フォルダと出力ファイル名には未使用の名前を指定してください。既存の生成先は受け付けず、結果ファイルも上書きしません。Python 3.12の起動名が`python3`なら、3行とも読み替えます。作業先と一時フォルダへの書込み権限が必要です。

例は実音声ではなく合成トーンです。監査の期待結果はPASS、音声59件中57件不変、字幕114件の表示文不変、許可された累積尺差222サンプルです。3行目のテストは別の検証で、これらの件数と合算しません。過去のLinux・Windowsの結果と未確認点は[検証記録](VALIDATION.md)に分けています。

## 自分の素材で使う

1. 最後に承認した版を修正前、編集結果を修正後にし、それぞれ別の固定コピーにする。
2. 各版の`audio/audio_report.json`、`audio/caption_timeline.json`と、参照するPCM WAVを用意する。[最小入力例](INPUT-FORMAT.md)と同じ形式が必要。無関係なJSONの名前だけを変えても使えない。
3. 比較結果を見る前に、変更を許可した音声IDをpolicyへ記す。音声内容・尺・字幕の発話内時刻は別々の許可。
4. `python audit.py before after policy.json --output result.json`を実行する。出力は新しいファイル名にする。
5. `status`だけでなく`violations`と`unknowns`を読む。掲載されていれば`effective_policy`・`audio_equality`・素材ごとの結果も確認する。警告を消すために許可を後付けしない。

| 結果 | 終了コード | 次にすること |
|---|---:|---|
| PASS | 0 | 対象範囲では許可外の変更が見つからなかった。許可した修正と完成物は別途確認する。 |
| FAIL | 1 | 指摘された差分を確認し、意図しない変更なら編集結果を直す。 |
| INCONCLUSIVE | 2 | 欠品・形式不備・未対応・結果保存失敗を解消する。途中までに検出した違反も無視しない。 |

## 普通のハッシュ比較との違い

ハッシュ比較は「ファイルが変わったか」を調べます。このツールはさらに、事前に指定したIDだけの変更か、許可した尺差に沿って後続音声・字幕の時刻が動いたかを確認します。JSONの申告値も実WAVと照合します。[比較表と正確な条件](COMPARISON-CONTRACT.md)を参照してください。

これは実装した機能の説明で、他製品より優れるという評価ではありません。外部利用実績や一連の作業の時短効果は未測定です。

## 限界と検証結果

- 通常の整数PCM WAVと指定JSON項目だけが対象。混在サンプルレート、WAVE_FORMAT_EXTENSIBLEは未対応。
- 字幕文・ページ構成は修正前後で維持する必要があります。字体、装飾、追加JSON項目、SRT、MP4は検査しません。
- 信頼できる静止した素材コピーを使います。悪意ある巨大ファイルへの防御や、基準版そのものの正しさは保証しません。
- 実制作の修正全体の合格、外部利用、時短効果は実証されていません。合成例の結果から、それらを推定しないでください。
- 最新のLinux検証と過去のWindows検証を分けて記録しています。Windowsの権限不足による試験省略を、Linux成功で確認済みにしません。[証拠と限界](VALIDATION.md) · [変更履歴](CHANGELOG.md)
